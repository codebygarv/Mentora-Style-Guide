# Mentora — Mobile App Design Style Guide & Showcase

> **Connect. Learn. Grow.**

Interactive style guide, design tokens, and high-fidelity mobile prototype showcases for **Mentora**, a mobile mentorship platform designed for 1:1 professional mentorship sessions.

## 🚀 Live Demo & Presentation
- **Hero Showcase**: Dynamic Command Center featuring interactive Mentee Dashboard.
- **Section 01**: Design System Tokens & Dual Theme Prototype (Light & Dark mode interactive phone).
- **Section 02**: Authentication & Onboarding Flows (Splash, Welcome, Sign In, Sign Up, Verify OTP, Reset Password).
- **Section 03**: Mentee Core Discovery & Booking (Dashboard, Explore Mentors, Mentor Profile, Booking Calendar, Payment).
- **Section 04**: Live Mentorship & Mentor Tools (Live 1-on-1 Video Session, Session Notes & Rating, Mentor Earnings Dashboard).

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS Design System with CSS Tokens & Glassmorphic variables
- **Typography**: Inter, Plus Jakarta Sans, Playfair Display

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
